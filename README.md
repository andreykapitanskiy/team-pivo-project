# Проект команды «Пиво»

Сквозной командный проект по дисциплине «Введение в профессиональную деятельность».

## О проекте
* **Тема проекта:** «Создание сервиса подбора хобби»
* **Учебная группа:** группа 644, бригада №4
* **Назначение:** Помощь пользователям в поиске интересного досуга и увлечений на основе их личных предпочтений, характера и свободного времени.

## Состав команды
* **Капитанский Андрей** — Руководитель проекта (Проектирование и координация задач)
* **Пустовой Борис** — Программист (Разработка программного кода)
* **Загрудный Данила** — Тестировщик (Проверка качества и поиск ошибок)
* **Зокиров Тимур** — Архитектор ПО (Проектирование логики и интерфейса)
* **Маскаев Владислав** — Специалист по данным (Проектирование и работа с базами данных)
